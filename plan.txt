১. On-Demand Offline Language Packs (ডাউনলোডযোগ্য অফলাইন প্যাক)
Base App Size: অ্যাপটি প্লে-স্টোরে সাধারণ ৩০-৪০ মেগাবাইট (MB) সাইজে আপলোড হবে। অ্যাপে প্রাইমারি ভাষা (যেমন: ইংরেজি/বাংলা) ইনস্ট্যান্ট অফলাইনে থাকবে।
Offline Language Manager: অ্যাপের সেটিংসে ১০৯টি ভাষার তালিকা থাকবে।
১ ক্লিকের অফলাইন প্যাক ডাউনলোড: ইউজার যখন জার্মান (de), ফ্রেঞ্চ (fr), বা হাঙ্গেরিয়ান (hu) সিলেক্ট করবে, অ্যাপ ব্যাকএন্ড থেকে মাত্র ৩–৫ মেগাবাইটের ১টি Compressed Database File একবার ডাউনলোড করে নিবে।
১০০% অফলাইন গ্যারান্টি: ডাউনলোড করার পর ইউজার মোবাইল ডেটা/ওয়াইফাই পুরোপুরি বন্ধ করে (Airplane Mode) দিলেও সারা জীবন সব হাদীস ও কনটেন্ট অফলাইনে পড়তে পারবে।


🛠️ ১. ব্যাকএন্ডে যা যা তৈরি করতে হবে (Backend Requirements):
Compressed Offline Pack Generator (প্যাক জেনারেটর):
ব্যাকএন্ডে ১টি ছোট অটোমেটেড স্ক্রিপ্ট থাকবে যা প্রতি ভাষার হাদীস ও কনটেন্টকে কম্প্রেসড করে ক্ষুদ্রাকৃতির ফাইল (যেমন: hadith_de.json.gz বা hadith_de.sqlite — সাইজ মাত্র ৩–৪ MB) হিসেবে জেনারেট করবে।
CDN / Cloud Storage:
ফাইলগুলো সার্ভারের /public/packs ফোল্ডারে বা AWS S3 / Cloudflare R2 ফাস্ট সিডিএন-এ হোস্ট রাখা হবে যাতে বিশ্বজুড়ে ইউজাররা ১ সেকেন্ডে ফাইল ডাউনলোড করতে পারে।
Sync & Version Control API:
GET /api/v1/hadith/check-sync?lang=de (চেক করবে কোনো নতুন হাদীস যোগ হয়েছে কিনা)।
GET /api/v1/hadith/download-pack?lang=de (ফ্রি ও ফাস্ট ডাউনলোডের লিংক প্রদান করবে)।
📱 ২. মোবাইল অ্যাপে যা যা থাকতে হবে (Mobile App Requirements):
Local SQLite / Hive Database Engine:
মোবাইলের অফলাইন মেমরিতে ডাটা রাখার জন্য অ্যাপে SQLite (sqflite/drift) বা Hive ডাটাবেজ ইন্টিগ্রেট করতে হবে।
Language Pack Manager UI:
সেটিংসে ১০৯টি ভাষার তালিকা থাকবে। প্রতিটি ভাষার পাশে "Download (3.4 MB)" বাটন, ডাউনলোডের প্রোগ্রেস বার (যেমন: 45%...), এবং ডাউনলোড শেষে "Offline Ready ✅" ব্যাজ দেখাবে।
Offline First Repository Pattern:
অ্যাপের কোড এমনভাবে হবে যেন যেকোনো হাদীস ওপেন করার সময় অ্যাপ আগে চেক করবে মোবাইলের অফলাইন ডাটাবেজে ডাটা আছে কিনা। থাকলে ইন্টারনেট ছাড়াই সরাসরি স্ক্রিনে প্রদর্শন করবে।
🤖 ৩. ১০৯টি ভাষার ডাটা কালেকশন (Translation Supply):
শীর্ষ ১০টি প্রধান ভাষা (বাংলা, ইংরেজি, উর্দু, ফ্রেঞ্চ ইত্যাদি):
FawazAhmed API থেকে ১ ক্লিকে বিনামূল্যে আমাদের তৈরি স্ক্রিপ্ট দিয়ে একবারে প্যাক জেনারেট করে ফেলা হবে।
অবশিষ্ট অন্যান্য ভাষাসমূহ:
আমরা পূর্বে যে OpenAI Batch API (gpt-4o-mini) আলোচনা করেছি, সেটি দিয়ে একবারে বাকি ভাষাগুলোর ব্যাকগ্রাউন্ড ব্যাচ ক্রিয়েট করে মাত্র ৫০-৬০ টাকায় পুরো অনুবাদ ডাটাবেজে ফাইল আকারে সেভ করে নেওয়া যাবে।
